# 定时任务管理

本模块承接已完成的普通与分片执行能力。用户于 2026-11-12 确认管理页面范围并授权实施，一级菜单名称为“定时任务”。本页记录管理行为与实现边界；历史保留和清理仍按[生命周期安排](operations.md)单独推进。

## 页面与导航

```text
系统管理
└─ 既有系统页面
定时任务
├─ 任务管理
├─ 执行记录
└─ 执行器组
```

“定时任务”与“系统管理”同级，三个页面均为二级菜单，由 System 的数据库菜单和角色菜单授权控制。个人中心及既有系统页面不因新增菜单改变。

| 页面 | 能力与入口 |
| --- | --- |
| 任务管理 | 查询、创建、详情、停用后编辑、启停、删除、Cron 预览及手动执行；查看执行记录时跳转同一历史页面并带 Job 条件 |
| 执行记录 | 查询 Instance 历史，进入本轮详情，再从 Task 列表查看单条详情；Instance 和 Task 详情不增加侧栏菜单 |
| 执行器组 | 列表、创建、详情及删除；名称与发现 Key 创建后固定；Token 默认遮挡，可主动显示和复制，列表不返回 Token |

组与 Job 的既有操作约束、停止规则和手动触发防重均保持。手动执行响应只确认创建执行记录；网络重试沿用同一操作的请求号和参数，明确另一次执行才建立新的操作。停止按后端返回的实际状态展示，STOPPING 不表示业务已经退出。

## 查询契约

| 入口 | 查询内容 |
| --- | --- |
| `POST /job/instance/list` | `page/pageSize` 以及可选的 Instance ID、Job ID、本轮 Job 名称、组 ID、状态、触发方式和创建时间上下界；返回总数与轻量列表 |
| `POST /job/instance/get` | 既有本轮事实、冻结配置及新增分片统计；普通任务的统计为 NULL |
| `POST /job/task/list` | 既有所属 Instance 的 Task 分页摘要，每页最多 200 条，按 ID 稳定排序 |
| `POST /job/task/get` | 按 Task ID 读取当前事实；`dataKind` 省略时仅元信息，`input` 或 `result` 时按需读取一份 JSON |

Instance 列表按 `created_at DESC, id DESC` 排序。时间使用带时区的 RFC 3339，区间为包含下界、不包含上界；仅给一侧也有效。创建时间同时覆盖计划、错失补执行和手动触发，不能拿自动计划时间代替。触发方式继续使用既有枚举：1 计划、2 错失补执行、3 手动。

历史 Job 名称使用 Instance 创建时快照，查询不依赖当前 Job 是否存在或停用。列表所需组名通过一次只读关联取得，包括保留的软删除组记录；不逐条补查。列表不读取冻结参数、执行摘要或 Task 数据。总数与当前页沿用现有分页查询方式，不保证与并发写入处于同一数据库快照。

按实际历史查询新增创建时间、Job 加创建时间、组加创建时间三个索引。状态和名称组合沿用过滤，不为每种组合建立索引；名称采用大小写不敏感的字面子串匹配。具体执行计划由真实 PostgreSQL 验证。

## 详情与数据

Instance 状态独立展示。Task 类型分别展示普通、准备、分片和收尾；不把执行阶段拼入父状态。分片统计只包含业务分片的总数、成功、失败、取消及未结束数，来自读取时的 Task 事实，不逐条回报更新父计数，不表示业务工作量百分比。零条记录不能单独证明准备完成或业务明确返回零分片。

Task 详情包含当前尝试、已用次数、执行器身份与地址、时间、结束原因及最近摘要，不构造不存在的逐次尝试历史。重试期间的最近摘要可能来自前次尝试，不能作为当前尝试已完成的证据。普通和 Pre 的共用参数从本轮冻结配置查看；`input_data` 保存分片或 Post 的固定输入。

输入和结果按用户操作加载，以 JSON 文本传输和展示，保留大整数精度。SQL NULL 表示未提供；JSON `null` 是已提供的 JSON 值，空数组也不能替换成缺失。

单份文档以 PostgreSQL JSONB 转为文本后的 UTF-8 字节数为准，最多 8 MiB；完整 GetTask protobuf 响应最多 9 MiB。两种超界均明确返回 `job.task.data_too_large`，不截断，也不改变原数据。API 仅为该管理 RPC 放宽接收上限，执行通信及其他方法的限制保持各自配置。大小与选中数据由同一查询判断，超界文档不跨越数据库连接；没有选择的数据不读取。该管理限制不等于执行器报文限制，JSONB 展开与两份数据之和也不能按原始请求大小推断。

## 刷新、权限与日志

三个列表默认手动刷新；打开的非终态 Instance 详情每 5 秒刷新摘要、统计和当前 Task 页，并可暂停。关闭、隐藏或进入终态后停止周期刷新。请求串行执行；切换 Instance、页码或筛选后，旧响应不覆盖当前目标。输入／结果不随周期刷新重复读取。

API 继续经过 System 登录、会话及角色接口权限，再调用 Job 管理 RPC；不另建权限体系。新增菜单与 API 迁移只登记资源，不自动给已有角色授权。组凭据、本轮参数和 Task 数据沿用内容日志保护，保留方法与耗时等运行信息。
